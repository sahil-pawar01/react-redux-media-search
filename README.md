
# 🔍 React Redux Media Search

A modern and interactive **Media Search Application** built using React.js and Redux Toolkit. The application allows users to search for photos and GIFs through external APIs, browse dynamic media results, manage their favourites, and maintain a personal media collection.

🌐 **Live Demo:** [React Redux Media Search](https://react-redux-media-search.vercel.app)

📂 **GitHub Repository:** [react-redux-media-search](https://github.com/sahil-pawar01/react-redux-media-search)

---

## ✨ Features

- **Media Search:** Search for photos and GIFs using external APIs.
- **Dynamic Media Browsing:** Explore media results based on search queries.
- **Favourites Management:** Save your favourite media for quick access.
- **Personal Collection:** Manage your saved media in one place.
- **Global State Management:** Efficient state management using Redux Toolkit.
- **API Integration:** Fetch media data dynamically using Axios.
- **Toast Notifications:** Interactive notifications for user actions.
- **Client-Side Routing:** Navigate between different application pages.
- **Responsive Design:** Optimized for different screen sizes and devices.
- **Modern UI:** Clean and user-friendly interface.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/sahil-pawar01/react-redux-media-search.git
```

### 2. Navigate to the Project Directory

```bash
cd react-redux-media-search
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

If the application requires API keys, create a `.env` file in the root directory and add the required API credentials.

```env
VITE_API_KEY=your_api_key
```

Replace the placeholder with the actual environment variable names used in your project.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
